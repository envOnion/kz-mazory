# Единый пункт настроек AI в Django Admin

Ветка: bugfix/admin-ai-settings-navigation. Основание: пользователь просит убрать два пункта меню, открывающих одну конфигурацию AI.

## Требования

В разделе «AI & Интеграции» оставить один пункт «Настройки AI», ведущий на существующий /admin/api/aisettings/. Удалить дублирующий пункт «Настройки анализа AI» из «Фоновых заданий». Страница сохраняет модели Chat/Embeddings, параметры анализа и автономного учёта в одном месте.

## Изменения и проверка

Изменить только UNFOLD sidebar в backend/mazory_backend/settings.py. Модели, схема БД и сами настройки AI не меняются. Проверить Django check, makemigrations --check и реальный HTML меню после развёртывания. Просмотреть логи backend/Q2/WAHA. Frontend не затрагивается.

## Критерии готовности

В меню один пункт с URL /admin/api/aisettings/, под названием «Настройки AI». Старые названия отсутствуют, страница настроек доступна по прежнему адресу. Production readiness и Django-проверки проходят.

## Результат

В UNFOLD SIDEBAR ровно один пункт для /admin/api/aisettings/: «Настройки AI». Дублирующий пункт из «Фоновых заданий» удалён. Сама страница и данные конфигурации не изменены.

Собран и развёрнут backend `mazory-backend:ai-settings-nav-20261006`, release `/home/a_belianskii/mazory-releases/ai-settings-nav-20261006`. Пересоздан только HTTP-backend; nginx прошёл nginx -t и reload для актуализации адреса upstream. Воркеры Q2, outbox, WAHA и БД не перезапускались.

Проверки: Django check без ошибок, makemigrations --check — No changes detected в новом образе с production-конфигурацией. Реальный HTTPS-вход администратора прошёл; HTML бокового меню содержит единственный переименованный пункт, старые подписи отсутствуют. Отдельная общая ссылка «Настройки моделей AI» остаётся в штатном переключателе всех моделей Django Admin и не является дублирующим пунктом бокового меню.
