# Закрытие внешнего 8080 и исправление перекрывающих окон админки

Задача: `admin-access-ingress`. Ветка: `bugfix/admin-access-ingress`.
Основание: пользователь потребовал закрыть внешний 8080 и исправить отображение /admin; уточнил, что менять MFA, авторизацию и её настройки не требуется.

## Причина и границы

На production браузер воспроизводит CSP EvalError в штатном Alpine.js из Unfold 0.108.0. Не исполняются x-show для openModal, shortcutsOpen и общего modal-overlay. Из-за этого затемнение и окно горячих клавиш постоянно перекрывают страницу и не закрываются.

Причина находится в заголовке CSP, который устанавливает backend/api/security.py. Требуется только совместимость этого заголовка с существующей админкой. Модели, БД, MFA, вход, зависимости и шаблоны MFA не меняются. Начатые изменения вне этой границы отменены до коммита и развёртывания.

## Изменения

- Закрыть внешний listener 8080 для IPv4 и IPv6, сохранить обычный HTTPS 443 → loopback 18080. Внутренний контейнерный 8080 frontend не публикуется наружу.
- Добавить unsafe-eval только в CSP ответов /admin/, чтобы штатный Alpine исполнял выражения управления интерфейсом. Остальные ограничения CSP и заголовки других маршрутов сохранить.
- Выставлять ту же CSP на /admin/ тестового окружения: браузерные тесты должны ловить эту production-ошибку.
- Добавить E2E: страница входа не перекрыта, модальное окно/справочник клавиш и overlay изначально скрыты; подсказки открываются и закрываются Escape/кликом снаружи, поля формы доступны; нет ошибок Alpine/CSP. Проверить также авторизованную страницу админки на синтетическом стенде.

## Готовность

- TCP 8080 снаружи закрыт, на сервере нет IPv4/IPv6 listener 8080; HTTPS 443 работает.
- Указанные пользователем перекрывающие блоки корректно скрываются, открываются и закрываются. Ошибок CSP/Alpine нет.
- MFA и её исходные настройки не изменены.
- Playwright E2E на localhost:5173, сборка/typecheck, Django check, makemigrations --check и тесты проходят; проверены логи worker/WAHA.
- PR в main, CI, merge и развёртывание узкого исправления на публичном сервере.

[Официальный контракт Alpine CSP](https://alpinejs.dev/advanced/csp/) подтверждает требование стандартной сборки к unsafe-eval. Исключение ограничивается существующей админкой Unfold.

## Проверки реализации

- В production удалён отдельный nginx listener 8080 (IPv4/IPv6). Внешнее TCP-подключение отклоняется; HTTPS 443 сохранён. Предыдущий конфиг сохранён вне сервера.
- `git diff` подтверждает отсутствие изменений MFA, её шаблона, settings и файлов зависимостей. Единственное изменение поведения — CSP в `api/security.py`.
- Django `check`: без ошибок. `makemigrations --check --dry-run`: `No changes detected`. Все 64 backend-теста прошли, включая ограничение CSP-исключения только /admin/.
- Frontend typecheck/Vite build прошёл. 12 прежних E2E успешно прошли; два новых теста после исправления ожиданий для анонимной страницы также прошли. Открытие/закрытие окна shortcuts проверяется на авторизованной странице, где Unfold выводит этот компонент; страница входа проверяется на доступность полей и отсутствие перекрытия.
- Логи изолированных очередей проверены; `crm_disabled` ожидаем для отключённого тестового CRM. Общий прогон всех 14 сценариев повторяется в CI перед merge.
