# Снять ограничение max-w-2xl во всей админке

- Задача: `admin-full-width`
- Ветка: `bugfix/admin-full-width`
- Статус: спецификация согласована пользователем («делай»); реализация и локальные проверки завершены.

## Постановка

Убрать ограничение максимальной ширины `max-w-2xl` во всей административной панели Django Unfold проекта Mazory.

## Требования

- Элементы админки с классом `max-w-2xl` должны использовать доступную ширину без ограничения в 42rem.
- Изменение должно действовать на всех административных страницах, включая формы и виджеты Unfold.
- Сохранить адаптивность и отсутствие горизонтального переполнения на узком экране.
- Не менять другие ограничения ширины, пользовательский Vue-интерфейс и файлы установленного пакета Unfold.
- Схема БД и модели не затрагиваются.

## Планируемые изменения

1. Добавить общий стиль `backend/static/mazory/css/admin_layout.css`, отменяющий `max-width` для `.max-w-2xl` и вариантов с `!important`, включая раскрывающиеся текстовые поля Unfold.
2. Подключить его глобально через `UNFOLD["STYLES"]` в `backend/mazory_backend/settings.py`.
3. Проверить реальные страницы админки через Playwright на широком и узком экране, выполнить существующие E2E-сценарии.
4. Выполнить сборку фронтенда, Django `check`, `makemigrations --check`, просмотреть логи сервисов.
5. После успешных проверок создать PR в `main` и выполнить предусмотренный репозиторием review.

## Критерии готовности

- На реальных страницах админки у элементов `.max-w-2xl` вычисленное значение `max-width` равно `none`.
- На широком экране поля могут занимать больше 42rem при достаточной ширине родителя.
- На узком экране нет горизонтального переполнения из-за изменения.
- Обязательные проверки проходят; существующие изменения другой задачи сохранены.

## Выполненная проверка

- Общий стиль подключён через `UNFOLD["STYLES"]`. Правило расположено в слое `base`, чтобы `!important` переопределял в том числе важные утилиты Unfold из слоя `utilities`.
- Playwright: 21 существующий E2E-сценарий прошёл успешно.
- Дополнительная браузерная проверка страниц AISettings, WhatsAppConfig и Project: `max-width: none`, поля шириной 1030px при экране 1600px; при экране 390px поля не выходят за доступную ширину. Проверены светлая и тёмная темы.
- Проверены скриншоты широкой и мобильной формы WhatsAppConfig.
- `npm run build`, Django `check` и `makemigrations --check` прошли; изменений схемы нет.
- Проверены логи backend, фоновых очередей, outbox и изолированного провайдера WAHA.
- Для сохранения окружения параллельной задачи использован отдельный Docker Compose project `mazory-admin-width-e2e`; тестовая копия конфигурации и сценариев использует локальный порт 5273 вместо занятого 5173. Изменения инфраструктуры проверки не входят в код приложения.
