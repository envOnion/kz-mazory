# Перемещение раздела «Личные настройки» ниже «Администрирование» в панели управления

- Задача: `admin-sidebar-order`.
- Создано: 06.10.2026, 02:05:13 MSK.
- Основание: прямое указание пользователя переместить раздел «Личные настройки» в боковом меню админки ниже раздела «Администрирование».
- Область: конфигурация Django Unfold Admin (`backend/mazory_backend/settings.py`) и регрессионный тест конфигурации. Схема БД и модели не изменяются.

## 1. Постановка задачи

В текущей конфигурации бокового меню панели администратора (`UNFOLD["SIDEBAR"]["navigation"]`) блок «Личные настройки» (содержащий пункт «Безопасность» с настройками двухфакторной аутентификации) расположен на самом верху списка навигации.
Необходимо изменить порядок разделов в боковом меню так, чтобы блок «Личные настройки» отображался ниже раздела «Администрирование» (в самом низу навигации).

## 2. Требования

1. В `backend/mazory_backend/settings.py` в словаре `UNFOLD["SIDEBAR"]["navigation"]` переместить блок:
   ```python
   {
       "title": "Личные настройки",
       "separator": True,
       "items": [
           {
               "title": "Безопасность",
               "icon": "security",
               "link": "/admin/security/",
           }
       ],
   }
   ```
   так, чтобы он следовал строго после блока:
   ```python
   {
       "title": "Администрирование",
       "separator": True,
       "items": [
           {
               "title": "Пользователи системы",
               "icon": "people",
               "link": "/admin/auth/user/",
           },
           {
               "title": "Профили сотрудников",
               "icon": "badge",
               "link": "/admin/api/userprofile/",
           },
       ],
   }
   ```
2. Сохранить все существующие разделы, иконки, ссылки, разделители и пункты меню без искажений.
3. Итоговый порядок разделов меню:
   - «Управление продажами»
   - «WhatsApp & WAHA»
   - «AI & Интеграции»
   - «Фоновые задания»
   - «Администрирование»
   - «Личные настройки»
4. Добавить регрессионный тест, проверяющий взаимное расположение разделов «Администрирование» и «Личные настройки» в структуре навигации `settings.UNFOLD`.
5. Модели Django и миграции схемы БД не затрагиваются (`python manage.py makemigrations --check` возвращает 0).
